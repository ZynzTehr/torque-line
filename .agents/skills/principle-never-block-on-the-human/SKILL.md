# Keep authorized work moving

Apply [agent efficiency](../../rules/agent-efficiency.md) and [the canonical autonomy policy](../../autonomy-config.md). They define when to proceed, what requires authorization, and how existing approval carries forward.

Before asking, determine whether tools or a small authorized experiment can resolve the uncertainty. Ask the user for product preferences that evidence cannot establish. If one action lacks authorization, prepare a concrete reviewable result and continue independent authorized work.

Reversibility does not grant scope. Record unrelated discoveries for the user rather than creating new tasks automatically. A request to continue preserves the selected profile.
