# Gaps found in the port and for production

An audit on 2026-10-27 compared every user-visible capability of the original FleetPulse app (ZynzTehr/fleet-pulse@88e9f01) with Torqueline, and reviewed Torqueline for production readiness. Of 176 capabilities checked, 57 were present, 43 partial, 65 missing, and 11 intentionally deferred (permits, insurance, Gemini key). This file lists the partial and missing ones, most important first. Delete a row when it ships.

Impact is for a fleet owner using the app day to day. Effort is a rough estimate.
