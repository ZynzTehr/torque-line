# Impeccable

A comprehensive design polish and hardening workflow for digital interfaces. Impeccable elevates functional UI into exceptional, production-grade craft through structured critiques, hardening passes, and micro-interaction polish.

## Core principles

- **Go all out:** Deliver complete, polished components, handling all edge cases, empty states, and responsive breakpoints.
- **Distinct POV:** Avoid bland, middle-of-the-road designs. Give each surface a clear hierarchy, intentional contrast, and memorable character.
- **Bounded verification:** Inspect rendered results on mobile and desktop viewports, fix defects in focused batches, and verify real interactions.

## Sub-commands and design heuristics

Execute the relevant heuristic when evaluating or refining an interface:

- **`audit`:** Scan the interface for layout bugs, optical misalignments, inconsistent spacing, broken contrast, and missing responsive states.
- **`critique`:** Evaluate visual hierarchy, cognitive load, content density, and narrative flow from a design director's perspective.
- **`clarify`:** Reduce visual noise, eliminate unnecessary containers and borders, and sharpen the core call to action.
- **`bolder`:** Elevate timid typography, enhance contrast, increase scale differences between headings and body, and create confident hero moments.
- **`delight`:** Add subtle micro-interactions, responsive hover states, spring transitions, and feedback animations that reward user input.
- **`colorize`:** Replace washed-out or generic hues with cohesive, accessible color palettes with thoughtful light and dark mode pairings.
- **`animate`:** Apply physics-based easing curves, staggered list entries, and smooth state transitions while respecting `prefers-reduced-motion`.
- **`adapt`:** Refine responsiveness across viewport boundaries, ensuring touch-friendly targets (minimum 44x44px) on mobile and dense ergonomics on desktop.
- **`distill`:** Strip ornamental clutter, redundant text, and extra clicks to focus strictly on user task completion.
- **`harden`:** Test edge cases: extreme text lengths, zero-state illustrations, network error toasts, and disabled loading states.
- **`polish`:** Fine-tune optical margins, font smoothing, kerning, border radii continuity, and layout grid alignments.
- **`extract`:** Turn refined styles into reusable CSS custom properties and design system component tokens.
