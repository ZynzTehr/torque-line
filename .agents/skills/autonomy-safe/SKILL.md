# Safe autonomy

Read [the canonical autonomy policy](../../autonomy-config.md), adjacent to the package's `AGENTS.md`. Apply its safe column when selected or when the configuration cannot be interpreted. That policy defines action categories, existing authorization, and profile changes.

Continue authorized local work and relevant research. Prepare externally visible or sensitive operations for review when authorization is missing. The user's request to keep working does not switch profiles. Do not maintain a separate permission table here.
